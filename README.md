Project Overview:
Moodly is a simple and user-friendly Flutter application that helps users track their daily moods. Users can select how they feel, write notes, and view their mood history. The app is designed with a clean UI and easy navigation.

Features:
Select your daily mood (Happy, Neutral, Sad, Angry)
Add notes about your day
View mood history
Simple profile screen
Bottom navigation for easy switching between screens
Clean and minimal UI design

Run the Project:
flutter pub get
flutter run
